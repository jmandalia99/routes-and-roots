Building blocks · anga

Three parts make every tala

A tala is spelled with the hand. Every one of the seven talas is just a sequence of these three units — and only the Laghu changes length.

How a tala is recited: each anga speaks its own syllables. The Laghu takes the jaati's sollukattu (tisra → Ta Ki Ta, chatusra → Ta Ka Dhi Mi …), the Drutam is always Ta Ka, the Anudrutam is a single Ta. So Ata tala in tisra reads TaKiTa · TaKiTa · TaKa · TaKa — ten beats, ten sollus.

The key distinction · jaati vs gati

Same names, different jobs

Both use the same five names — Tisra to Sankeerna — and that is exactly why they confuse. But one shapes the cycle; the other fills each beat.

Jaati — the structure

How many boxes

Sets the Laghu length, so it decides how many beats are in the row. Change the jaati and the whole cycle grows or shrinks.

2
3

↑ more boxes = longer tala

Gati / Nadai — the texture

What's inside each box

Subdivides every beat into equal pulses. The number of boxes never changes — only how densely each one is filled.

↑ tisra gati = 3 pulses per box

In one line: Jaati sets the shape — how many beats are in the cycle, and which sollukattu you recite through them. Gati sets the pulse — how many matras tick inside every single beat (3, 4, 5, 7 or 9). Speed sets the flow — 1, 2 or 4 sollus per beat, running on across the cycle and landing back on sam. All three dials are independent: change the jaati and the gati stays exactly where you left it.

Concept · trikaala

What "three speeds" means

Your hand keeps the same tala at the same tempo. What changes is how many sollus flow through each beat — one, then two, then four. The phrase runs on across the beats and lands back on sam. Example: chatusra jaati, Eka tala, 4 beats.

FIRST SPEED
Prathama

One sollu per beat — the phrase fills the cycle once.

Ta · Ka · Dhi · Mi
SECOND SPEED
Dvitiya

Two per beat — twice through.

TaKa · DhiMi · TaKa · DhiMi
THIRD SPEED
Tritiya

Four per beat — four times through.

TaKaDhiMi · ×4
It keeps flowing: the cycle's sollukattu is exactly as long as the cycle, so in second speed it runs through twice and the beats cut across it. Tisra Eka: Ta Ki Ta in first speed, then TaKi · TaTa · KiTa in second, then TaKiTaTa · KiTaTaKi · TaTaKiTa in third. Same three beats, same tempo; only the flow doubles. Meanwhile the gati keeps its own pulse inside each beat, untouched by any of this.
